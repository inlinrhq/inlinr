# Inlinr — community

Feature requests, questions and roadmap discussion for
[Inlinr](https://inlinr.com), time tracking for developers.

The product itself is closed-source, so this repository exists purely so the
conversation is not. Nothing here is a code repository — it is Discussions and
Issues.

## Where to go

| | |
|---|---|
| **Request an editor or an AI tool** | [Discussions → Ideas](https://github.com/inlinrhq/inlinr/discussions/categories/ideas) |
| **Report a bug** | [Issues](https://github.com/inlinrhq/inlinr/issues) |
| **See what's planned** | [inlinr.com/roadmap](https://inlinr.com/roadmap) |

Reactions are how the roadmap gets reordered. An editor ten people ask for
moves ahead of one nobody has mentioned — which is more useful than a form
that disappears into an inbox.

## Roadmap

Mirrors [inlinr.com/roadmap](https://inlinr.com/roadmap), which is the
reference. Nothing is listed as available until it works in production.
Last updated 14 Oct 2026.

### Editors and assistants

| | Status |
|---|---|
| VS Code | ✅ Available |
| Cursor | ✅ Available |
| Windsurf | ✅ Available |
| Claude Code (terminal, desktop, IDE, cloud) | ✅ Available |
| Any editor with a WakaTime plugin, through a WakaTime-compatible API | 🔨 In progress |
| JetBrains (IntelliJ, WebStorm, PyCharm, GoLand, Rider) | 💭 Considering |
| Neovim | 💭 Considering |

### Product

| | Status |
|---|---|
| AI attribution, Claude Code tokens and cost | ✅ Available |
| Teams, with seat-based billing | ✅ Available |
| Client share links | ✅ Available |
| Invoices and versioned hourly rates | ✅ Available |
| WakaTime import | ✅ Available |
| Dependency tracking (npm, opt-in per project) | ✅ Available |
| Public profile and README card | ✅ Available |
| Shipped vs edited code | 🔨 In progress |
| AI costs on client invoices, with a budget per project | 💭 Considering |
| Time per ticket, read from the branch name | 💭 Considering |
| Calendar import into manual entries | 💭 Considering |

Something missing? Open an idea in
[Discussions](https://github.com/inlinrhq/inlinr/discussions/categories/ideas),
or add a 👍 to an existing one.
