# Security

If you find a vulnerability in Inlinr (inlinr.com, the editor extensions, the
CLI or the Claude Code plugin), email **support@inlinr.com** with:

- what you found and where,
- the steps to reproduce it,
- what an attacker could do with it.

Please do not open a public issue or discussion, and do not access other
people's data beyond what you need to show the problem.

You will get an answer within 3 working days. Once it is fixed, we are happy to
credit you in the changelog if you want.

How Inlinr handles data is described at [inlinr.com/security](https://inlinr.com/security).
