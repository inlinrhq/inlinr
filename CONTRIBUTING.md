# Contributing

Inlinr's server is not open-source, so this repository has no code to send
pull requests to. What helps most:

- **Vote** on a planned idea with a 👍 on its
  [roadmap issue](https://github.com/inlinrhq/inlinr/issues?q=is%3Aissue+is%3Aopen+label%3Aroadmap).
  The [roadmap](https://inlinr.com/roadmap) is ordered by those votes.
- **Suggest** something new in
  [Discussions → Ideas](https://github.com/inlinrhq/inlinr/discussions/categories/ideas).
  Describe the problem first; the solution can come later.
- **Report a bug** with the
  [bug report form](https://github.com/inlinrhq/inlinr/issues/new?template=bug_report.yml).
  The version, editor and `inlinr doctor` output save a round trip.
- **Ask** in [Discussions → Q&A](https://github.com/inlinrhq/inlinr/discussions/categories/q-a).

The editor extensions and the CLI are public repositories and accept pull requests:
[inlinr-vscode](https://github.com/inlinrhq/inlinr-vscode),
[inlinr-cli](https://github.com/inlinrhq/inlinr-cli) and
[inlinr-claude-code](https://github.com/inlinrhq/inlinr-claude-code).

Everyone here follows the [code of conduct](CODE_OF_CONDUCT.md).
